Todoist 연결

Todoist 로그인으로 오늘 할 일을 불러오고, 복습 할 일을 다시 추가합니다.

OAuth PKCE 방식으로 연결합니다. 토큰은 이 브라우저에만 저장되며 서버에 따로 보관하지 않습니다.

API 토큰 직접 입력

Notion 연결

Notion 로그인으로 학습노트를 저장할 데이터베이스를 선택합니다. 저장은 본인이 연결한 워크스페이스에만 됩니다.

Notion 로그인 필요

Notion 로그인 화면에서 학습노트를 저장할 페이지/데이터베이스에 접근을 허용해주세요. 데이터베이스에 "제목" 속성은 자동으로 인식되고, 과목/날짜/유형 속성은 이름이 비슷하면 자동으로 채워집니다.

오늘의 학습 큐

Todoist 또는 직접 입력한 할 일에서 학습 작업을 고릅니다.

학습 설정

선택한 작업에 맞춰 프롬프트가 자동으로 바뀝니다.

Claude 프롬프트

6가지 프롬프트 원칙을 반영해 생성됩니다.

Notion용 Markdown

Claude 결과를 붙여넣으면 템플릿에 옮기기 좋게 정리합니다.

복습 루프

학습노트 생성 후 Todoist에 복습 할 일을 다시 넣습니다.
